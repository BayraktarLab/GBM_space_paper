# GBMspace: A spatiotemporal cancer cell trajectory underlies glioblastoma heterogeneity

Code repository for analysis and figure plotting related to the GBMspace project.

## Repository contents

- `metadata` - Metadata associated with the project.
- `data` - Contains source data for GBMspace figures, provided the data is storage efficient. Please see the [GBMspace portal](https://www.gbmspace.org/) for larger files such as h5ads.
- `code` - Contains code related to major analyses. Please see the disclaimer below for more details.

## Code availability
Code from GBMspace has been collected and organised in this repo by primary section topic.
Within each topic directory, code is separated into subdirectories outlining `Analysis` and `Figure` code, whereever relevant. For broader topics which involved analysis of multiple modalities, subdirectories are listed within each directory (e.g. `5.CELLULAR_TRAJECTORIES/Analysis/GBOExperiment/`).

`Analysis` directories contain custom scripts and notebooks related to data processing.

`Figure` directories contain notebooks associated with downstream analysis and data visualisation.

## Data availability
Please see the [GBMspace portal](https://www.gbmspace.org/) for our spatial and single nucleus multiome data. Source data for figures is provided in `data` where possible.
